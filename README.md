# DecanatPRO

Учебное приложение для учёта студентов на C# и .NET 8.

Решение находится в `lab1/DecanatPRO.slnx` и включает проекты Model, BusinessLogic, ConsoleApp и WinFormsApp.

Для запуска консоли: `dotnet run --project lab1/ConsoleApp`

Для запуска оконного приложения в Windows: `dotnet run --project lab1/WinFormsApp`
